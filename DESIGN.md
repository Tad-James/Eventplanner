Reference inspected 26 October 2026: https://bychenai.com/

The reference was retrieved as HTML, read through web search, and inspected visually in a desktop browser at its full-screen opening image and first editorial introduction. The Firecrawl connector returned an unavailable-tool error. Its exact mobile rules, interaction implementation, and spacing were not established.

## Observed reference patterns

- Full-screen event photograph, centred identity and restrained framing.
- Ivory / near-white editorial sections, serif and italic headings, small tracked sans-serif labels.
- Large portrait photography paired with open text compositions.
- Separate event portfolio, service information, personal story, praise and contact paths.
- The retrieved CSS names Bodoni, Bodoni Italic, Silver South Serif and La Bohemia. The browser screenshot establishes the serif/sans contrast; no reference font files are reused.

## BG. identity retained

The source site CSS establishes Cormorant Garamond and Manrope; ink `#0d0b0a`, ivory `#f8f3eb`, gold `#b8915a`, and maroon `#7a1712`. The company's round burgundy seal is reused from `/brand/seal.png`. Fonts are self-hosted copies of those already delivered by the company's website.

## Proposed implementation

- Light ivory canvas, burgundy links and calls to action, muted gold rules and details.
- A split opening composition rather than reproducing the reference's full-screen splash.
- Cormorant display headings with selective italics; Manrope for navigation and body text.
- Asymmetric featured event pairs, numbered service links, plain process steps and short verified review excerpts.
- Responsive breakpoint decisions are original: desktop split hero, tablet split with constrained headline, phone stacked text and photography. No claim of pixel-identical reproduction.
- Hover motion and smooth anchors, disabled for reduced-motion preferences; no autoplay or scroll-jacking.
- Native HTML navigation and forms, local assets, semantic headings, visible keyboard focus and labelled controls.

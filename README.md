# BG. Event Management

Static, buildless, responsive website. Published files live in `dist/`; HTML, `sitemap.xml` and `robots.txt` are generated by `python3 build.py`. CSS and JavaScript are edited directly in `dist/assets/`.

## Contact

There is no enquiry form. Every call to action leads to `/contact/` (or the floating button) where visitors choose **Chat on WhatsApp** (prefilled message to +91 97915 14367) or **Call**. Nothing is collected or stored by the site.

## Deploy on Vercel

`vercel.json` sets `dist` as the output directory, no build step, trailing-slash URLs, security and cache headers, and a redirect from the retired `/plan/` page to `/contact/`.

1. Import the repository in Vercel (Framework Preset: **Other**; leave build and install commands empty).
2. Deploy. `404.html` is served automatically for unknown paths.
3. After attaching your domain, regenerate canonical URLs and the sitemap with `SITE_URL=https://your-domain python3 build.py` and commit `dist/`. The default is `https://www.bgeventmanagement.in`.

## Security

No third-party scripts, trackers or remote requests. A per-page `<meta>` Content-Security-Policy restricts scripts, styles, images and fonts to the site (the JSON-LD block is SHA-256 allow-listed by `build.py`). External links use `noopener noreferrer`.
